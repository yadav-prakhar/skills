# Execution planning workflow

1. Freeze the approved brief, drawings, dimensions, finishes and scope.
2. List work packages and dependencies (survey, design approval, procurement, demolition, civil, electrical, carpentry, finishes, installation, testing).
3. For each package define owner, prerequisite, duration estimate, access needs, protection, inspection and acceptance criteria.
4. Build itemized schedules and a budget separating materials, delivery, taxes, labour, installation, civil/electrical work and contingency.
5. Obtain comparable written quotations with brands/models, quantities, exclusions, warranty and payment milestones.
6. Identify permits, apartment approvals and qualified trades.
7. Plan site protection, dust/noise management, waste disposal and temporary loss of room use.
8. Test lighting, switches, hardware, doors, drawers, ventilation, water protection and finish quality.
9. Handover manuals, warranties, spare materials, as-built dimensions and defect list.
