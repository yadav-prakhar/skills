# Room redesign workflow

1. Define outcomes, constraints, retained items, budget and deadline.
2. Inspect each photo independently; record evidence, camera position, occlusions and missing views.
3. Request a measured plan when layout or custom joinery depends on dimensions. Never scale precise dimensions from perspective photos.
4. Map activities, circulation, daylight, ventilation, storage and maintenance.
5. Develop up to three distinct directions only when comparison is useful.
6. Resolve layout and large furniture before finishes and decoration.
7. Audit existing lighting and power access before proposing fixtures.
8. Prepare a zone-by-zone proposal separating existing, removed, relocated and new items.
9. Check dimensions, movement, mounting, power, maintenance, budget, permissions and specialist work.
10. State the next decision or measurement needed.
